# 🎮 Game Store Fullstack Application

A full-stack Game Store CRUD application built using:

- Frontend: React + TypeScript + Vite
- Backend: ASP.NET Core Web API (.NET 10)
- Database: SQLite
- Deployment:
  - Frontend → Vercel
  - Backend → Render
